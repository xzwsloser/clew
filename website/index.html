Install & Start Reading in 60 Seconds

Clew plugs straight into DeepSeek Harness — no separate API gateway or per-repo IDE indexing required.

01

Build & Register Plugin

git clone https://github.com/xzwsloser/clew.git
cd clew
pnpm install --ignore-scripts
pnpm run build
dsh plugin --profile web add "$(pwd)/packages/plugin"
02

Launch DSH & Import Repo

dsh web --port 18765 --host 127.0.0.1

Open Clew from the left navigation rail, click + Import Repo, and point to any local directory or HTTPS/SSH Git URL.

03

Trace, Compare & Annotate

  • Submit a reading goal to generate a verified call/dependency graph.
  • Press Cmd/Ctrl+P for symbol jump or Cmd/Ctrl+Shift+F for ripgrep search.
  • Highlight lines to Peek structs, inspect Git history, Ask AI, or save Reading Paths.
